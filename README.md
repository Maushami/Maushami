# Maushami Gadhia

**Senior Full Stack Engineer** — Angular · C#/.NET · AWS · Murrieta, California

Nine years building enterprise web platforms. At **The Toro Company** I own frontend architecture
for a cloud irrigation management platform and work across its .NET and AWS backend. Most
recently I led its incremental upgrade from **Angular 15 to 22** with no feature freeze, along
with a **PrimeNG 15 → 22** migration and a move to Signals and zoneless change detection.

I care about reusable UI architecture, event-driven systems that stay maintainable as they grow,
and leaving a codebase easier to work in than I found it.

---

## What I work on

**Frontend architecture**\
Angular (v11–22, Signals, zoneless), TypeScript, RxJS, PrimeNG, SCSS and design tokens.
Shared component libraries, themeable layout systems, and large version migrations.

**Backend and cloud**\
C#, .NET, ASP.NET Core Web API on AWS Lambda, SQL Server and T-SQL, DynamoDB single-table design.
Event-driven services on AWS: AppSync GraphQL subscriptions and SQS FIFO queues.

**Geospatial**\
MapLibre GL JS with AWS Location Service: device mapping, coverage polygons, interactive overlays.

**Testing**\
Vitest, Jasmine, Playwright, NUnit, Moq.
